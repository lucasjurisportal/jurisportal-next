# Guia do proprietário - sem precisar saber programar

## O que estamos fazendo

Você não precisa aprender a programar para acompanhar o projeto.

Pense assim:

- **Tela** = o que o advogado enxerga.
- **Banco de dados** = onde as informações ficam guardadas.
- **Backend** = o funcionário invisível que confere regras e conversa com o banco.
- **API externa** = outro sistema que empresta um serviço ou informação ao Jurisportal.
- **Deploy** = colocar o sistema na internet.

## O que já tínhamos

Tínhamos principalmente as telas e a experiência desenhadas.

Isso é como ter uma casa decorada em maquete: sabemos onde fica cada cômodo, mas água, luz e encanamento ainda não estavam ligados.

## O que a v23 começou

Criamos a primeira parte da fundação real:

- tabela oficial de planos;
- preço promocional e preço regular;
- regra automática da promoção;
- capabilities por plano;
- IA somente Premium+;
- limites internos para a IA;
- arquitetura para impedir código espaguete;
- documentação para outro programador entender as decisões.

## O próximo passo

Precisamos do banco de dados na nuvem.

Sem banco real, Login, Cliente, Processo e Prazo continuam sendo apenas demonstração.

Quando chegarmos a esse passo, você só fará ações de conta, como:

1. criar a conta no serviço indicado;
2. clicar para criar um projeto;
3. me fornecer os nomes/valores de configuração necessários de forma segura;
4. nunca publicar senha ou chave em GitHub.

Eu fornecerei cada clique na ordem. Não presumo que você saiba onde fica nada.

## Regra importante

Se uma etapa exigir que você crie conta, aceite termos, faça pagamento, valide domínio ou gere chave externa, o desenvolvimento para antes dessa etapa e a instrução é dada primeiro.
