LIMITAÇÃO DO AMBIENTE DE EMPACOTAMENTO
O ZIP de origem não contém node_modules e o ambiente de empacotamento não possui todas as dependências npm em cache.
Por isso, o typecheck/build completo deve ser executado no ambiente local do projeto, onde npm install já foi concluído.

VALIDAÇÃO LOCAL OBRIGATÓRIA
1. npm run typecheck
2. npm run test:reports
3. npm run build
4. npm run dev
5. abrir /app/relatorios
6. testar período, CSV e impressão/salvar PDF
